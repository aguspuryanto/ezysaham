## Tentang IDX Market Data API
Data pasar Bursa Efek Indonesia (IDX) dalam satu API: quote real-time, chart intraday hingga bulanan, running trade, orderbook, dan order queue.

Pantau aliran dana asing dan broker (bandarmology), top movers, kalender corporate action, berita emiten, transaksi insider, serta laporan keuangan dan key stats setiap saham.

## Charts
Quote
A live price snapshot for one stock: last traded price and change, day open / high / low, VWAP, volume, value, trade count, best bid and ask with their sizes, the day's price limits (ARA / ARB), market status and any special notations.

Intraday
Intraday price bars for one stock, newest first by default ('order=asc' for oldest first).

Daily
Daily, weekly or monthly price bars for one stock, newest first by default ('order=asc' for oldest first).
