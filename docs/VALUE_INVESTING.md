# Value Investing Screener

saham valuasi murah & fundamental bagus
PER < 7, PBV < 1

Kriteria screener saham
Indikator	Kriteria	Tujuan
PER	< 7	Valuasi murah
PBV	< 1	Di bawah nilai buku
ROE	> 10%	Profitabilitas bagus
DER	< 1	Utang terkendali
Net Profit	Positif	Perusahaan menghasilkan laba
Revenue Growth	Positif	Pendapatan bertumbuh
EPS Growth	Positif	Laba per saham bertumbuh
Current Ratio	> 1	Likuiditas memadai

Catatan: untuk sektor perbankan, DER dan Current Ratio tidak cocok digunakan dengan standar perusahaan non-keuangan. Bank perlu dinilai dengan indikator seperti CAR, NPL, ROA, dan NIM.

kategori hasil:
- A – Strong Value: seluruh kriteria terpenuhi.
- B – Potential Value: valuasi murah, tetapi ada indikator fundamental yang perlu diperiksa.
- C – Value Trap: murah karena kinerja bisnis sedang memburuk.
