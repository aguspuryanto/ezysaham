### 🔌 Integrasi API & Model Data

Buat fungsi fetch terpusat di `lib/api.ts` untuk memanggil ketiga endpoint ezysaham. Karena API eksternal, sebaiknya gunakan **Route Handler** Next.js sebagai proxy (`/api/stocks`) untuk menghindari CORS dan menyembunyikan URL asli.

```typescript
// lib/types.ts
export interface Stock {
  symbol: string;
  name: string;
  price: number;
  change: number;       // persentase perubahan
  volume: number;
  marketCap: number;
  peRatio: number;
  dividendYield: number;
  // ... field lain sesuai respons ezysaham
}

export interface Candle {
  time: string;         // YYYY-MM-DD
  open: number;
  high: number;
  low: number;
  close: number;
  volume: number;
}

export interface Fundamentals {
  symbol: string;
  per: number;
  pbv: number;
  roe: number;
  der: number;
  // ...
}
```

```typescript
// lib/api.ts
const BASE = "https://ezysaham.vercel.app/api";

export async function fetchStocks(): Promise<Stock[]> {
  const res = await fetch(`${BASE}/stocks`, { next: { revalidate: 300 } }); // cache 5 menit
  if (!res.ok) throw new Error("Gagal memuat data saham");
  return res.json();
}

export async function fetchHistory(symbol: string, range = "6mo"): Promise<Candle[]> {
  const res = await fetch(`${BASE}/stocks/${symbol}/history?range=${range}`, {
    next: { revalidate: 600 }, // 10 menit
  });
  return res.json();
}

export async function fetchFundamentals(symbol: string): Promise<Fundamentals> {
  const res = await fetch(`${BASE}/stocks/${symbol}/fundamentals`, {
    next: { revalidate: 3600 },
  });
  return res.json();
}
```

> **Catatan**: `revalidate` pada `fetch` memastikan data tidak terlalu sering diambil, sesuai kebutuhan jeda 5–15 menit. Untuk portofolio, kita bisa memaksa refresh manual.

### 📊 Screener Saham & Analisa Teknikal untuk Pemula

#### Logika Screener (Top Gainer, Momentum, Dividen, Fundamental, Akumulasi)

Buat fungsi kalkulasi di `lib/indicators.ts`. Screener dapat dijalankan di sisi klien setelah data `fetchStocks()` dimuat.

```typescript
// lib/indicators.ts
import { Stock, Candle } from "./types";

// RSI (14 periode) — indikator overbought/oversold untuk pemula
export function calcRSI(closes: number[], period = 14): number | null {
  if (closes.length < period + 1) return null;
  let gains = 0, losses = 0;
  for (let i = 1; i <= period; i++) {
    const diff = closes[i] - closes[i - 1];
    if (diff >= 0) gains += diff;
    else losses -= diff;
  }
  const avgGain = gains / period;
  const avgLoss = losses / period;
  if (avgLoss === 0) return 100;
  const rs = avgGain / avgLoss;
  return 100 - 100 / (1 + rs);
}

// SMA
export function calcSMA(closes: number[], period: number): number | null {
  if (closes.length < period) return null;
  return closes.slice(-period).reduce((a, b) => a + b, 0) / period;
}

// MACD sederhana (12, 26, 9)
export function calcMACD(closes: number[]) {
  const ema = (data: number[], p: number) => {
    const k = 2 / (p + 1);
    return data.reduce((acc, val, i) => (i === 0 ? val : val * k + acc * (1 - k)), 0);
  };
  if (closes.length < 26) return null;
  const ema12 = ema(closes.slice(-26), 12);
  const ema26 = ema(closes.slice(-26), 26);
  return { macd: ema12 - ema26 }; // signal line bisa ditambahkan
}
```

**Definisi Screener:**

- **Top Gainer**: Urutkan `stocks` berdasarkan `change` tertinggi.
- **Top Momentum**: Gabungkan `change` tinggi + volume tinggi (misal: `change > 3% && volume > avgVolume`).
- **Top Dividen**: Urutkan berdasarkan `dividendYield` tertinggi.
- **Top Fundamental**: Filter `peRatio` wajar (< 20) dan `roe` tinggi, atau skor komposit sederhana.
- **Top Akumulasi**: Deteksi dari data history (volume naik saat harga sideways) atau gunakan field `volume` vs rata-rata.

  );
}

### 📈 Chart Saham (Candlestick + Indikator)

Untuk chart finansial, **TradingView Lightweight Charts** adalah pilihan paling profesional dan ringan (~12 KB gzip). Gunakan **dynamic import** dengan `ssr: false` karena library ini membutuhkan DOM.

```tsx
// components/charts/CandlestickChart.tsx
"use client";
import { useEffect, useRef } from "react";
import { createChart, CandlestickSeries, LineSeries } from "lightweight-charts";
import { Candle } from "@/lib/types";

export function CandlestickChart({ data, sma20, sma50 }: {
  data: Candle[];
  sma20?: { time: string; value: number }[];
  sma50?: { time: string; value: number }[];
}) {
  const ref = useRef<HTMLDivElement>(null);
  const chartRef = useRef<ReturnType<typeof createChart> | null>(null);

  useEffect(() => {
    if (!ref.current) return;
    const chart = createChart(ref.current, {
      width: ref.current.clientWidth,
      height: 360,
      layout: { background: { color: "transparent" }, textColor: "#888" },
      grid: { vertLines: { color: "#333" }, horzLines: { color: "#333" } },
    });
    chartRef.current = chart;

    const candleSeries = chart.addSeries(CandlestickSeries, {
      upColor: "#26a69a", downColor: "#ef5350", borderVisible: false,
    });
    candleSeries.setData(data);

    if (sma20) {
      const line = chart.addSeries(LineSeries, { color: "#f59e0b", lineWidth: 2 });
      line.setData(sma20);
    }
    if (sma50) {
      const line = chart.addSeries(LineSeries, { color: "#3b82f6", lineWidth: 2 });
      line.setData(sma50);
    }

    const handleResize = () => chart.applyOptions({ width: ref.current!.clientWidth });
    window.addEventListener("resize", handleResize);
    return () => { window.removeEventListener("resize", handleResize); chart.remove(); };
  }, [data, sma20, sma50]);

  return <div ref={ref} className="w-full" />;
}
```

**Indikator untuk Pemula**: Tampilkan **SMA 20 & 50** (tren), **RSI** (overbought >70 / oversold <30), dan **MACD** (persilangan garis) dengan penjelasan tooltip singkat.

### 💼 Manajemen Portofolio

Karena tidak ada backend khusus, simpan portofolio di **`localStorage`** melalui custom hook. Ini cukup untuk aplikasi support mobile tanpa login.

```typescript
// hooks/usePortfolio.ts
"use client";
import { useState, useEffect } from "react";

export interface Holding {
  symbol: string;
  avgPrice: number;
  shares: number;
}

export function usePortfolio() {
  const [holdings, setHoldings] = useState<Holding[]>([]);

  useEffect(() => {
    const saved = localStorage.getItem("portfolio");
    if (saved) setHoldings(JSON.parse(saved));
  }, []);

  const save = (next: Holding[]) => {
    setHoldings(next);
    localStorage.setItem("portfolio", JSON.stringify(next));
  };

  const addHolding = (h: Holding) => save([...holdings, h]);

  const removeHolding = (symbol: string) => save(holdings.filter((x) => x.symbol !== symbol));

  return { holdings, addHolding, removeHolding };
}
```

**Fitur Portofolio yang Direkomendasikan untuk Investor Pemula**:
- Daftar kepemilikan (saham, harga beli rata-rata, jumlah lot).
- **Total nilai pasar** dan **unrealized P/L** (dihitung dari harga terkini).
- **Alokasi sektor** dalam donut chart (Recharts).
- Peringatan sederhana jika satu sektor > 40% (diversifikasi).

### 🌗 Light/Dark Mode & Responsivitas Mobile

- Gunakan **`next-themes`** untuk toggle tema. Bungkus `layout.tsx` dengan `ThemeProvider`.
- **Mobile-first**: 
  - Sidebar disembunyikan di mobile, diganti **bottom navigation** atau **sheet** (shadcn/ui `Sheet`).
  - Tabel diganti card view di breakpoint `sm`.
  - Chart menggunakan `width: 100%` dan resize listener.

```tsx
// app/layout.tsx (ringkas)
import { ThemeProvider } from "next-themes";
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="id" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  );
}
```
